Client work — Custom software

An e-wallet app, driven through its steps

The Challenge

Wallet flows are long. Open, confirm, move, confirm again. A person can do it once. Doing it the same way every time, and being able to show that it happened, is the actual work.

The Solution

The script takes the path through the app and the session is recorded so the client can see the steps, not just a green checkmark in a log. If a screen is missing, the run stops where a person would stop. It does not guess a password or reach into an account the client cannot already open.
